SCM-OTP 放到 GitHub 之後能不能用

現在 docs\vault.json 還是空的。只 push 上去，網站會開，但還沒有 OTP。
綁定 QR 有時效、再申請很麻煩：一定要看到「倉庫已保存 N 筆」才能換電腦。

第一次（只做一次，QR 過期前做完）
1. 把整個 C:\SCM-OTP 建成 GitHub 倉庫並 push（不要推 data\）
2. Settings → Pages → Deploy from a branch → main → /docs
3. Chrome 開 https://你的帳號.github.io/倉庫名/
4. 按 ⚙ 填 owner、repo，貼 Token（contents:write）
5. 按 ＋ 上傳 014109、016035 的「綁定 QR」截圖（不要傳大數字畫面）
6. 必須出現「已寫進 GitHub／倉庫已保存 2 筆」
7. 若出現黃字「還沒寫進 GitHub」，按「再存進 GitHub」，不要關分頁

之後
- 任何電腦、清快取，開同一個網址就有 OTP，不必再傳 QR
- 不必再輸入 OTP 密碼
- 只有要新增／刪除帳號才需要 Token
